What this site is for

A GitHub-friendly version of the project deliverable

The original project already includes a Streamlit demo and a full IEEE-style article. This site is a separate static presentation layer designed for GitHub deployment, where all content has to be precomputed and fixed into HTML, CSS, JavaScript, and exported visuals.

Core claim

The best model depends on the operating mode

  • Accuracy-focused selection delivers the strongest overall multiclass score.
  • Sensitivity-first training recovers substantially more melanoma cases.
  • Calibration and subgroup analysis add constraints that neither score captures alone.

Dataset framing

HAM10000 is clinically useful precisely because it is messy

The dataset mixes seven lesion classes, lesion-wise grouping, metadata, severe class imbalance, and real ambiguity between melanoma and benign pigmented lesions. That makes evaluation choices as important as backbone choice.
